## 核心卖点

**「每一锄下去，都是未来的一亩良田。」**

玩家扮演勤奋的农场主，开荒、种植、合成与生活建设并行；作物按现实时间生长，随时可种、成熟可收。

## 核心闭环

```
劳动 → 土地 → 产出 → 货币/材料 → 工具/基建/生活建设 → 更高效劳动 + 更强归属感
```
