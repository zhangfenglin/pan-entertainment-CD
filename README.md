## 核心卖点

**「每一锄下去，都是未来的一亩良田。」**

玩家扮演勤奋的农场主，在荒芜之地使用工具开荒、管理精力与时间，建立可持续的农场经济；作物按现实时间生长，随时可种、成熟可收。
