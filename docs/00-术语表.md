## 系统关联速查

```
01 概述 ──→ 世界观、设计目标
02 玩法 ──→ 开荒 / 工具 / 种植（核心 loop）
03 经济 ──→ 货币 / 市场 / Sink（资源闭环）
04 事件 ──→ 天气 / 野兽 / 本地天气（扰动层）
05 成长 ──→ 等级 / 科技 / 雇工（长期 progression）
06 数值 ──→ 比率 / UI / 配置结构（落地参考）
07 生长 ──→ 作物生长周期 / 现实时间 / 随时可种可收
```

## 设计约束（全局）

1. 本地天气仅作**权重修正**，不引入季节系统
2. 每种资源至少 **1 来源 + 2 消耗点**
3. 每个事件至少 **2 种应对方式**
4. 开荒是投资，不是一次性动作——副产物、ROI、账本均需反馈
5. **无季节、无过季**：作物成熟后永久可收，仅占用地块
