## 1.1 核心概念

**《开荒》** 是一款以**土地开垦 + 农场经营**为核心的休闲策略游戏。玩家扮演一位来到荒芜之地的勤奋农场主，从一片未开发的野地出发，通过工具、精力与时间，逐步将荒地变为高产农田，并在此基础上建立可持续的农场经济。

## 1.2 设计目标

| 维度 | 目标 |
|------|------|
| 情感体验 | 从「一无所有」到「沃野千里」的成就感 |
| 核心乐趣 | 规划开荒顺序、工具搭配、精力与时间分配 |
| 策略深度 | 短期收益 vs 长期投入、风险与回报权衡 |
| 经济闭环 | 开荒 → 种植 → 出售/加工 → 再投资开荒 |
| 沉浸感 | 可选接入玩家本地天气，增强真实代入 |

## 1.3 一句话卖点

**「每一锄下去，都是未来的一亩良田。」**

## 2. 世界观与设定

### 2.1 背景

玩家因故来到一片**被遗忘的边境荒原**——土壤板结、杂草丛生、偶有石块与枯木。当地仅有零星流浪商队与旧驿站，无现成农田。玩家需从零开始，用劳动换土地，用土地换生存，再换更大规模的开荒能力。

### 2.2 地图结构（由近及远）

```
[安全区：旧驿站 / 简陋居所]
    ↓
[近郊荒地] → [灌木丛] → [石砾地] → [沼泽边缘] → [远郊未探明区域]
```

| 区域 | 特点 |
|------|------|
| 近郊 | 开荒成本低，适合新手与基础作物 |
| 中距 | 需更好工具与更多精力，回报更高 |
| 远郊 | 高风险（天气、野兽事件），高价值作物与稀有资源 |

### 2.3 主角设定

- **身份**：勤恳农场主，无特殊超能力，靠工具与规划成长
- **成长线**：体力上限、工具熟练度、农业知识、商业信誉

---

## 3. 玩家核心决策

玩家在任意时刻都在回答三个问题：

1. **今天体力花在哪？** — 开荒、种植、应对事件
2. **这季种什么？** — 市场、季节、肥力约束
3. **钱是先还债还是先买犁？** — 现金流与长期投资

## 5. 商业化预留（若 F2P/付费）

| 类型 | 建议 | 原则 |
|------|------|------|
| 外观 | 工具皮肤、农场装饰 | 不影响数值 |
| 便利 | 账本扩展、地图标记 | 不直接卖资源 |
| 赛季通行证 | 声望加速、限定装饰 | 可选，非 P2W |
| **避免** | 直接卖铜币 / 跳过开荒 | 破坏核心体验 |
