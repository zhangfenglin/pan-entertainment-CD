## 1. 主循环（日 / 季为单位）

```mermaid
flowchart LR
    A[规划今日行动] --> B[消耗精力开荒]
    B --> C[地块进入可种植状态]
    C --> D[播种/浇水/施肥]
    D --> E[等待生长/季节推进]
    E --> F[收获]
    F --> G[出售/加工/储存]
    G --> H[购买工具/种子/补给]
    H --> A
```

---

## 2. 开荒子循环（单次行动）

1. **选择目标地块**（查看地形、障碍类型、预估工作量）
2. **选择工具**（效率、耐久、是否匹配障碍）
3. **确认行动** → 消耗**精力** + 占用**时间槽**
4. **结算**：地块状态推进（如：杂草 → 翻土 → 平整 → 可种植）
5. **可能触发**：随机事件（详见 [04-随机事件系统](./04-随机事件系统.md)）

## 3. 土地与开荒系统

### 3.1 地块状态机

| 状态 | 说明 | 可进行的操作 |
|------|------|--------------|
| 未探索 | 迷雾覆盖 | 侦察（消耗时间） |
| 原始荒草 | 高杂草、低肥力 | 割草、烧荒（可选） |
| 板结土 | 需翻土 | 锄地、松土 |
| 石砾混合 | 含石块 | 拣石、碎石化 |
| 平整地 | 可播种 | 施肥、播种 |
| 熟化田 | 连续种植后 | 更高产量加成 |
| 休耕地 | 玩家主动休耕 | 恢复肥力 |

**开荒进度示例**（一块标准 1×1 地块）：

```
原始荒草(100%) → 割草(60%) → 翻土(30%) → 平整(0%) → 可种植
```

每次有效劳动减少「剩余工作量」，不同工具效率不同。

### 3.2 障碍类型与对应工具

| 障碍 | 推荐工具 | 低效工具 | 备注 |
|------|----------|----------|------|
| 高草/灌木 | 镰刀、柴刀 | 锄头 | 可能获得纤维、木材 |
| 板结土 | 锄头、犁 | 手 | 消耗精力高 |
| 石块 | 鹤嘴锄、撬棍 | 普通锄 | 石块可收集出售 |
| 树根 | 斧、铁锹 | 镰刀 | 获得木材 |
| 积水/沼泽 | 排水渠、水泵 | 普通工具 | 需前置基建 |

### 3.3 开荒的精力消耗

**基础公式**：

```
精力消耗 = 基础工作量 × 工具系数 × 地形系数 × (1 - 熟练度加成)
```

| 机制 | 说明 |
|------|------|
| 精力上限 | 初始 100，随等级、装备、食物提升 |
| 自然恢复 | 每游戏小时 +5 |
| 睡眠 | 跨日恢复至 80%～100% |
| 食物/药水 | 即时或持续恢复 |

### 3.4 时间冷却系统

时间以**游戏内小时/天**推进，行动占用**时间槽**：

| 行动类型 | 占用时间 | 冷却/限制 |
|----------|----------|-----------|
| 单次锄地 | 2 小时 | 无 |
| 整块区域烧荒 | 4 小时 | 季节限制（干燥季） |
| 工具修理 | 1～6 小时 | 需在工作台 |
| 商队交易 | 固定每周一次 | 错过需等下一周期 |
| 作物生长 | 按品种 3～30 天 | 不可加速（付费道具可选） |

**设计原则**：

- 同一天精力耗尽后，仍可安排「低精力」活动（规划、交易、研究）
- 重要决策（先开哪块地）受**季节窗口**约束，形成策略压力

## 4. 工具系统

### 4.1 工具属性

| 属性 | 说明 |
|------|------|
| 效率 | 减少工作量的倍率 |
| 耐久 | 使用次数或耐久值，归零需修理 |
| 适用类型 | 对哪些障碍有加成 |
| 精力修正 | 使用该工具时精力消耗增减 |
| 品质 | 普通 / 精良 / 大师，影响以上各项 |

### 4.2 工具列表

| 工具 | 获取方式 | 主要用途 | 经济定位 |
|------|----------|----------|----------|
| 木锄 | 初始赠送 | 基础翻土 | 零成本起点 |
| 铁锄 | 购买/锻造 | 效率 +40% | 第一个里程碑投资 |
| 镰刀 | 购买 | 割草 | 开荒必备 |
| 鹤嘴锄 | 锻造 | 碎石化 | 中期解锁石砾地 |
| 简易犁 | 图纸+材料 | 大面积翻土 | 后期规模化 |
| 水车/水泵 | 基建 | 排水灌溉 | 长期投资 |

### 4.3 工具熟练度

- 长期使用同一类工具 → **熟练度提升** → 精力消耗降低、小概率不耗耐久
- 鼓励专精，也保留「换工具开新区域」的取舍

## 5. 种植与生产系统

### 5.1 作物分级

| 层级 | 代表作物 | 土地要求 | 周期 | 风险 |
|------|----------|----------|------|------|
| T1 | 土豆、萝卜 | 平整地即可 | 短 | 低 |
| T2 | 小麦、玉米 | 需施肥 | 中 | 中（天气） |
| T3 | 棉花、药草 | 熟化田 | 长 | 中 |
| T4 | 稀有药草、经济作物 | 特定地形+设施 | 很长 | 高 |

### 5.2 肥力与连作

- 每块地有**肥力值**（0～100）
- 连续种植同种作物 → 肥力下降 → 产量降低
- **轮作、休耕、绿肥**可恢复并提升上限

### 5.3 加工链

```
原料 → 初级加工 → 高级商品
小麦 → 面粉 → 面包（溢价 2～3 倍）
棉花 → 布匹 → 衣物（溢价 3～5 倍）
药草 → 药剂 → 高价卖给商队/任务
```

加工消耗**时间**与**设施**（磨坊、织布机、炼药台），形成二次投资 loop。详见 [03-经济体系](./03-经济体系.md)。
