## 1. 主循环（日 / 季为单位）

```mermaid
flowchart LR
    A[规划今日行动] --> B[消耗精力开荒]
    B --> C[地块进入可种植状态]
    C --> D[播种/浇水/施肥]
    D --> E[等待生长/季节推进]
    E --> F[收获]
    F --> G[出售/加工/储存]
    G --> H[购买工具/种子/补给]
    H --> A
```

---

## 2. 开荒子循环（单次行动）

1. **选择目标地块**（查看地形、障碍类型、预估工作量）
2. **选择工具**（效率、耐久、是否匹配障碍）
3. **确认行动** → 消耗**精力** + 占用**时间槽**
4. **结算**：地块状态推进（如：杂草 → 翻土 → 平整 → 可种植）
5. **可能触发**：随机事件（详见 [04-随机事件系统](./04-随机事件系统.md)）

## 3. 土地与开荒系统

### 3.1 地块状态机

| 状态 | 说明 | 可进行的操作 |
|------|------|--------------|
| 未探索 | 迷雾覆盖 | 侦察（消耗时间） |
| 原始荒草 | 高杂草、低肥力 | 割草、烧荒（可选） |
| 板结土 | 需翻土 | 锄地、松土 |
| 石砾混合 | 含石块 | 拣石、碎石化 |
| 平整地 | 可播种 | 施肥、播种 |
| 熟化田 | 连续种植后 | 更高产量加成 |
| 休耕地 | 玩家主动休耕 | 恢复肥力 |

**开荒进度示例**（一块标准 1×1 地块）：

```
原始荒草(100%) → 割草(60%) → 翻土(30%) → 平整(0%) → 可种植
```

每次有效劳动减少「剩余工作量」，不同工具效率不同。

### 3.2 障碍类型与对应工具

| 障碍 | 推荐工具 | 低效工具 | 备注 |
|------|----------|----------|------|
| 高草/灌木 | 镰刀、柴刀 | 锄头 | 可能获得纤维、木材 |
| 板结土 | 锄头、犁 | 手 | 消耗精力高 |
| 石块 | 鹤嘴锄、撬棍 | 普通锄 | 石块可收集出售 |
| 树根 | 斧、铁锹 | 镰刀 | 获得木材 |
| 积水/沼泽 | 排水渠、水泵 | 普通工具 | 需前置基建 |

### 3.3 开荒的精力消耗

**基础公式**：

```
精力消耗 = 基础工作量 × 工具系数 × 地形系数 × (1 - 熟练度加成)
```

| 机制 | 说明 |
|------|------|
| 精力上限 | 初始 100，随等级、装备、食物提升 |
| 自然恢复 | 每游戏小时 +5 |
| 睡眠 | 跨日恢复至 80%～100% |
| 食物/药水 | 即时或持续恢复 |

### 3.4 时间冷却系统

时间以**游戏内小时/天**推进，行动占用**时间槽**：

| 行动类型 | 占用时间 | 冷却/限制 |
|----------|----------|-----------|
| 单次锄地 | 2 小时 | 无 |
| 整块区域烧荒 | 4 小时 | 季节限制（干燥季） |
| 工具修理 | 1～6 小时 | 需在工作台 |
| 商队交易 | 固定每周一次 | 错过需等下一周期 |
| 作物生长 | 按品种 3～30 天 | 不可加速（付费道具可选） |

**设计原则**：

- 同一天精力耗尽后，仍可安排「低精力」活动（规划、交易、研究）
- 重要决策（先开哪块地）受**季节窗口**约束，形成策略压力

## 4. 工具系统

### 4.1 工具属性

| 属性 | 说明 |
|------|------|
| 效率 | 减少工作量的倍率 |
| 耐久 | 使用次数或耐久值，归零需修理 |
| 适用类型 | 对哪些障碍有加成 |
| 精力修正 | 使用该工具时精力消耗增减 |
| 品质 | 普通 / 精良 / 大师，影响以上各项 |

### 4.2 工具列表

| 工具 | 获取方式 | 主要用途 | 经济定位 |
|------|----------|----------|----------|
| 木锄 | 初始赠送 | 基础翻土 | 零成本起点 |
| 铁锄 | 购买/锻造 | 效率 +40% | 第一个里程碑投资 |
| 镰刀 | 购买 | 割草 | 开荒必备 |
| 鹤嘴锄 | 锻造 | 碎石化 | 中期解锁石砾地 |
| 简易犁 | 图纸+材料 | 大面积翻土 | 后期规模化 |
| 水车/水泵 | 基建 | 排水灌溉 | 长期投资 |

### 4.3 工具熟练度

- 长期使用同一类工具 → **熟练度提升** → 精力消耗降低、小概率不耗耐久
- 鼓励专精，也保留「换工具开新区域」的取舍

## 5. 种植与生产系统

### 5.1 作物分级

| 层级 | 代表作物 | 土地要求 | 周期 | 风险 |
|------|----------|----------|------|------|
| T1 | 土豆、萝卜 | 平整地即可 | 短 | 低 |
| T2 | 小麦、玉米 | 需施肥 | 中 | 中（天气、过季） |
| T3 | 棉花、药草 | 熟化田 | 长 | 中～高（过季窗口窄） |
| T4 | 稀有药草、经济作物 | 特定地形+设施 | 很长 | 高（错过季节损失大） |

### 5.2 肥力与连作

- 每块地有**肥力值**（0～100）
- 连续种植同种作物 → 肥力下降 → 产量降低
- **轮作、休耕、绿肥**可恢复并提升上限

### 5.3 收割窗口与过季损失

每种作物在成熟后拥有有限的**收割窗口**——必须在当前季节结束前完成收获。若因精力不足、事件占用、规划失误等原因**错过窗口**，将产生实质性损失，而非无限期等待。

#### 作物生长阶段

```
播种 → 生长中 → 可收割（进入窗口）→ 过季（窗口关闭）
                      ↑
                 玩家应在此区间完成收割
```

#### 收割窗口规则

| 项目 | 说明 |
|------|------|
| 窗口开启 | 作物达到「可收割」状态时触发 UI 提醒 |
| 窗口长度 | 因品种而异：T1 约 5～7 游戏日，T2 约 3～5 日，T3/T4 约 2～4 日 |
| 季节边界 | 季节切换时强制结算所有未收割地块 |
| 重叠行为 | 窗口内可分批收割；雇工可代为执行（效率 80%） |

#### 过季损失等级

季节切换时，对仍在「可收割」或「未成熟」状态的地块按以下规则结算：

| 状态 | 损失类型 | 典型结果 |
|------|----------|----------|
| 可收割 · 刚错过（缓冲 1 日） | 品质衰减 | 产量 -30%，仅可贱卖或作饲料 |
| 可收割 · 完全过季 | 作物报废 | 产量归零，投入种子/肥料成本全损 |
| 未成熟 · 过季 | 绝收 | 无产出，需额外清理地块 |
| 连作风险叠加 |  pest 权重 ↑ | 下季同科作物事件权重 +15% |

**缓冲日说明**：每季最后 1 个游戏日设为「抢收日」，仍允许收割但产量 -30%；进入下一季节零点则按「完全过季」结算。新手保护期（前 1 季）缓冲损失减半。

#### 损失构成（进入账本）

```
地块 #7 · 小麦过季未收
  种子成本：-8 铜（已消耗，无法回收）
  肥料成本：-5 铜
  劳动机会成本：-12 铜（播种/浇水/施肥）
  作物收益：0（本季无产出）
  清理费用：-3 铜（移除枯株、恢复可播状态）
  ─────────────────
  本期净损：-28 铜
  副产物：枯麦秆 ×2（可作燃料，+2 铜）
```

#### 应对与减损手段

| 手段 | 成本 | 效果 |
|------|------|------|
| 提前规划 | 无 | 在日历上预留收割日，避免窗口末集中劳动 |
| 雇工代收 | 工资（铜） | 窗口期内自动收割，防遗漏 |
| 简易仓/地窖 | 建造 | 窗口内收割后可暂存，延至下季初 1～2 日出售（T1/T2 适用） |
| 急收令 | 消耗 20 精力 | 当日内强制完成指定区域收割，产量 -10% |
| 作物保险 | 每季保费 | 过季损失赔付 50%～70%（见 [03-经济体系](./03-经济体系.md)） |
| 轮作计划 | 研究时间 | UI 显示「本季最晚播种日」，从源头避免来不及成熟 |

#### 与精力/时间的交叉

- 成熟作物不占用每日精力，但**占用地块与季节时间**——拖延收割等于把地锁死，错过下一季播种窗口
- 同一季节内「开荒 vs 抢收」是典型冲突：地开得越多，收割日越紧张
- 随机事件（暴雨、兽害）可能占用时间槽，间接导致过季——见 [04-随机事件系统](./04-随机事件系统.md)

#### 设计意图

1. 让**季节**成为硬约束，而非装饰
2. 惩罚「只种不收」的无限囤积心态
3. 与精力、事件系统形成三角张力：扩张 / 应对 / 抢收
4. 保险、雇工、仓窖提供减损路径，而非纯惩罚

### 5.4 加工链

```
原料 → 初级加工 → 高级商品
小麦 → 面粉 → 面包（溢价 2～3 倍）
棉花 → 布匹 → 衣物（溢价 3～5 倍）
药草 → 药剂 → 高价卖给商队/任务
```

加工消耗**时间**与**设施**（磨坊、织布机、炼药台），形成二次投资 loop。详见 [03-经济体系](./03-经济体系.md)。
