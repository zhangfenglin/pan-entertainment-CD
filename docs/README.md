# 《开荒》游戏设计文档

> 一款以土地开垦与农场经营为核心的休闲策略游戏。玩家扮演勤奋的农场主，在荒芜之地用工具、精力与时间，将野地变为沃野良田。

## 设计一句话

**「每一锄下去，都是未来的一亩良田。」**

## 核心闭环

```
劳动（精力+时间）→ 土地 → 产出 → 货币 → 工具/基建 → 更高效劳动
```
