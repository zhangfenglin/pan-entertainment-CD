# 《开荒》游戏设计文档

> 一款以土地开垦与农场经营为核心的休闲策略游戏。玩家扮演勤奋的农场主，在荒芜之地用工具、精力与时间，将野地变为沃野良田。

## 设计一句话

**「每一锄下去，都是未来的一亩良田。」**

## 核心闭环

```
劳动 → 土地 → 产出 → 货币/材料 → 工具/基建/生活建设 → 更高效劳动 + 更强归属感
```

## 配置目录

```
config/
  crop-growth.json       # 作物生长周期
  materials.json         # 材料定义与产出
  recipes.json           # 合成配方
  life-progression.json  # 住宅、道路、伴侣
  weather-mapping.json   # 本地天气映射
```
