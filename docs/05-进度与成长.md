## 1. 玩家等级线

| 等级段 | 解锁内容 | 经济意义 |
|--------|----------|----------|
| Lv1～5 | 近郊、木/铁工具、T1 作物 | 学会基础 loop |
| Lv6～15 | 中距、加工、商队 | 加工溢价出现 |
| Lv16～30 | 远郊、雇工、贷款 | 规模化 |
| Lv30+ | 全图、大师工具、出口专线 | 终局优化 |

---

## 2. 科技/知识树

| 分支 | 效果 |
|------|------|
| 土力学 | 减少开荒工作量 |
| 作物学 | 解锁高阶种子、提高品质 |
| 工匠 | 降低工具成本、解锁图纸 |
| 贸易 | 更好收购价、商队频率 |
| 生态学 | 降低野生动物入侵频率、解锁共生契约 |

**投入**：声望 + 铜币 + 研究时间（占用时间槽，与劳动竞争）

---

## 3. 雇工系统（中后期）

| 项目 | 说明 |
|------|------|
| 功能 | 雇佣 NPC 代为执行低决策劳动（重复锄地、浇水） |
| 消耗 | 工资（铜）+ 管理时间 |
| 效率 | 低于玩家，但解放精力做开荒/交易 |
| 经济定位 | **货币 → 时间** 的转换器 |
| 事件影响 | 野兽袭击可能降低雇工士气，需额外安抚或防护 |

## 4. 事件与风险（经济扰动摘要）

完整事件设计见 [04-随机事件系统](./04-随机事件系统.md)。

| 事件 | 影响 | 玩家应对 |
|------|------|----------|
| 干旱 | 水类作物减产，收购价↑ | 提前建灌溉、改种耐旱作物 |
| 虫害 | 随机地块损失 | 买农药（Sink）、轮作 |
| 商路中断 | 远城高价订单暂停 | 转本地市场或储存 |
| 工具断裂 | 额外修理费 | 备用工具、熟练度降损 |
| 发现矿点/古物 | 一次性银币收入 | 改变开荒优先级 |
| 野生动物入侵 | 作物/设施损失 | 防护、猎捕、共生 |
| 本地天气联动 | 提前预警或突发灾害 | 排水、覆盖、保险 |

## 5. 难度曲线

| 阶段 | 体验目标 |
|------|----------|
| 前 2 小时 | 几乎无失败，教学 loop |
| 第 1 周（游戏内） | 首次季节截止压力 |
| 第 1 季 | 第一次「地不够/钱不够」双资源紧张 |
| 第 2～3 季 | 加工与商队成为主要利润来源 |
| 中后期 | 随机事件 + 远郊扩张形成主要挑战 |
