# 07 · 作物生长与时间节奏

---

## 1. 设计原则

《开荒》**不设季节系统**。时间节奏完全由**各作物的生长周期**驱动：

| 原则 | 说明 |
|------|------|
| 随时可种 | 任意时刻满足土地条件即可播种，无季节限制 |
| 成熟可收 | 生长倒计时结束后进入「可收割」，玩家方便时收取即可 |
| 周期宜短 | 单株作物从播种到成熟以**小时**计，适配碎片时间 |
| 后台生长 | 离线期间作物照常生长，上线即可处理成熟作物 |
| 无强制过期 | 成熟作物不会因子时间推移而报废或过季 |

**核心原则**：

> **玩家按自己的生活节奏上线，游戏只负责把「该收了」清楚告诉他。**

---

## 2. 时间结构

```mermaid
flowchart LR
    P[播种] --> G[生长中]
    G --> R[可收割]
    R --> H[玩家收割]
    H --> P
```

| 阶段 | 说明 | 玩家操作 |
|------|------|----------|
| 生长中 | 倒计时进行中，可离线 | 可选：浇水/施肥（缩短周期或提产） |
| 可收割 | 倒计时归零，永久保持至收割 | 登录提醒，任意时间一键收取 |
| 已收割 | 地块回到可播状态 | 可立即再种 |

**不存在**：季节切换、收割窗口关闭、过季损失、抢收日。

---

## 3. 作物生长周期（标准值）

采用**现实时间**计时（离线继续），周期按层级递增：

| 层级 | 代表作物 | 标准生长时长 | 加速后最短 | 土地要求 |
|------|----------|--------------|------------|----------|
| T1 | 土豆、萝卜 | **1 小时** | 45 分钟 | 平整地 |
| T2 | 小麦、玉米 | **3 小时** | 2 小时 | 平整地 + 可选施肥 |
| T3 | 棉花、药草 | **8 小时** | 6 小时 | 熟化田 |
| T4 | 稀有药草 | **18 小时** | 14 小时 | 特定地形 + 设施 |

### 3.1 设计意图

- **T1（1h）**：单次午休或通勤前后可完成一轮「种—收」
- **T2（3h）**：半个下午，适合下班后挂机等成熟
- **T3（8h）**：白天种下、下班收，或隔夜一批
- **T4（18h）**：长线投资，不要求当日盯盘

### 3.2 可选加速（非季节绑定）

| 手段 | 效果 |
|------|------|
| 浇水 | 进行中作物剩余时间 -10%（每块地每日 1 次） |
| 施肥 | 进行中作物剩余时间 -15%，且产量 +10% |
| 设施加成 | 温室等永久缩短该区域内作物 10%～20% 生长时间 |

### 3.3 成熟后行为

| 项目 | 规则 |
|------|------|
| 停留时限 | **无上限**，成熟作物一直保持可收状态 |
| 地块占用 | 未收前地块不可再种，形成「该收啦」的轻提示 |
| 品质 | 不因等待而下降（无「过季」「腐烂」机制） |
| 提醒 | 推送 / 游戏内角标：「3 块地已成熟」 |

## 4. 与时间相关的玩家操作

### 4.1 仍消耗时间槽的操作

以下动作即时完成，占用游戏内**时间槽**与**精力**：

| 操作 | 占用时间 | 说明 |
|------|----------|------|
| 单次锄地/开荒 | 2 小时（游戏内） | 与作物生长倒计时无关 |
| 播种 | 1 小时（游戏内） | 播下后开始生长倒计时 |
| 收割 | 1 小时（游戏内） | 成熟后执行 |
| 工具修理 | 1～6 小时（游戏内） | 即时队列 |

### 4.2 游戏内日 vs 现实时间

| 类型 | 推进方式 |
|------|----------|
| 作物生长 | **现实时间**，离线继续 |
| 精力恢复 | 游戏内「结束今日」或现实日切（可配置） |
| 商队刷新 | 每 **7 现实日** 一次，与季节无关 |

玩家无需在特定「季节」登录；只需在作物成熟时抽空收割即可。

## 5. 节奏模式（可选）

仅调节**生长速度倍率**，不改变「随时可种、成熟可收」规则：

| 模式 | 生长倍率 | 适合 |
|------|----------|------|
| 休闲 | ×1.5（更快） | 时间少、希望多收几轮 |
| 标准 | ×1.0 | 默认 |
| 沉浸 | ×0.75（更慢） | 希望拉长单株 ROI 决策 |

---

## 6. 雇工与离线体验

| 功能 | 行为 |
|------|------|
| 雇工自动收 | 作物成熟后自动收割（产量 80%），释放地块 |
| 离线生长 | 默认开启，无上限离线时长 |
| 登录摘要 | 「离线 6 小时：2 块成熟，1 块距成熟 40 分钟」 |

不要求玩家在工作日固定打卡；**成熟提醒**而非**截止惩罚**。

---

## 7. UI 要点

| 界面 | 内容 |
|------|------|
| 地块卡片 | 生长进度条 + 剩余时间（现实时钟） |
| 待收列表 | 所有「可收割」地块聚合，支持批量收取 |
| 种植面板 | 任意作物随时可选（仅受土地/种子限制） |
| 通知 | 「你的萝卜已成熟，随时可收」 |

**避免**：「距季节结束还有 X 天」「即将过季」类文案。

---

## 8. 与随机事件的关系

- 天气/兽害可能影响**进行中**作物（减产、暂停生长数小时），但不引入季节边界
- 事件示例：暴雨 → 当前生长中作物额外 +30 分钟；已成熟待收作物不受影响
- 详见 [04-随机事件系统](./04-随机事件系统.md)

## 10. 验收标准

1. 新玩家 30 分钟内可完成 T1 播种 → 成熟 → 收割全流程  
2. 工作日仅晚上登录 20 分钟，仍可管理所有已成熟作物  
3. 连续 3 天未登录，上线后成熟作物均可正常收取，无报废  
4. 任意时刻打开种植界面，均可选择已解锁作物播种
