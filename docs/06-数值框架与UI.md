## 1. 首日体验目标

| 目标 | 指标 |
|------|------|
| 完成首次开荒 | 30 分钟内完成 3～5 格开荒 + 种下第一批 T1 |
| 首次出售 | 获得 50～80 铜 |
| 首次资源紧张 | 引导完成订单/副产物出售 |

---

## 2. 关键比率（建议起点）

| 比率 | 目标值 |
|------|--------|
| 劳动时间 : 等待时间 | 40% : 60% |
| 开荒投资回本季数 | 1.5～3 季 |
| 加工溢价 | 2～5 倍 |
| 单季净利率（成熟农场） | 15%～25% |
| 重大基建占当季收入 | 30%～50% |

---

## 3. 关键 UI 界面

| 界面 | 功能 |
|------|------|
| 地图视图 | 地块状态、障碍图标、预估 ROI |
| 日计划面板 | 精力条、时间槽、行动队列 |
| 季节日历 | 当前季节剩余天数、各作物收割窗口倒计时 |
| 过季预警 | 地块标黄（窗口 < 2 日）、标红（抢收日/已过季） |
| 市场面板 | 动态价格、趋势箭头、商队倒计时 |
| 账本 | 收支明细、每块地累计利润 |
| 开荒预览 | 选工具 → 显示精力/时间/耐久/成功率 |
| 天气灵感条 | 本地天气映射、风险建议（可选） |
| 事件日志 | 前兆、爆发、应对记录与损失折算 |

## 5. MVP 功能清单（Playable 最小集）

| 优先级 | 系统 | 说明 |
|--------|------|------|
| P0 | 地块开荒 | 1 种障碍 + 2 种工具 + 精力/时间消耗 |
| P0 | 基础种植 | T1 作物 1～2 种，生长、收割窗口与过季损失 |
| P0 | 驿站市场 | 买卖铜币闭环 |
| P0 | 日计划 UI | 精力条 + 时间槽 |
| P1 | 动态价格 | 季节系数 + 简单供需 |
| P1 | 工具耐久与修理 | 第一个 Sink |
| P1 | 天气事件 ×2 | 干旱 + 暴雨各 1 条完整链 |
| P1 | 野兽事件 ×1 | 野兔或田鼠完整链 |
| P2 | 本地天气接入 | 城市级，权重修正 |
| P2 | 账本与 ROI 预览 | 策略反馈 |
