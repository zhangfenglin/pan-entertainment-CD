## 1. 首日体验目标

| 目标 | 指标 |
|------|------|
| 完成首次开荒 | 30 分钟内完成 3～5 格开荒 + 种下第一批 T1 |
| 首次出售 | 获得 50～80 铜 |
| 首次资源紧张 | 引导完成订单/副产物出售 |

---

## 2. 关键比率（建议起点）

| 比率 | 目标值 |
|------|--------|
| 劳动时间 : 等待时间 | 40% : 60% |
| 开荒投资回本 | 约 1.5～3 轮完整种植循环 |
| 加工溢价 | 2～5 倍 |
| 成熟农场利润率 | 15%～25%（按周估算） |
| 重大基建占当周收入 | 30%～50% |

---

## 3. 关键 UI 界面

| 界面 | 功能 |
|------|------|
| 地图视图 | 地块状态、障碍图标、预估 ROI |
| 日计划面板 | 精力条、时间槽、行动队列 |
| 待收列表 | 所有「可收割」地块聚合，显示成熟时间与批量收取 |
| 生长进度 | 每块地现实时间倒计时、预计成熟时刻 |
| 市场面板 | 动态价格、趋势箭头、商队倒计时 |
| 账本 | 收支明细、每块地累计利润 |
| 开荒预览 | 选工具 → 显示精力/时间/耐久/成功率 |
| 天气灵感条 | 本地天气映射、风险建议（可选） |
| 事件日志 | 前兆、爆发、应对记录与损失折算 |
| 家园视图 | 住宅等级、升级材料、维护状态 |
| 道路模式 | 铺路预览、材料消耗、移动增益 |
| 关系面板 | 好感、阶段、赠礼、协作冷却 |
| 材料图鉴 | 来源、用途、库存、市价 |
| 合成台 | 配方、队列、卖原料 vs 合成利润对比 |

## 5. MVP 功能清单（Playable 最小集）

| 优先级 | 系统 | 说明 |
|--------|------|------|
| P0 | 地块开荒 | 1 种障碍 + 2 种工具 + 精力/时间消耗 |
| P0 | 基础种植 | T1 作物 1～2 种，现实时间生长、成熟可收 |
| P0 | 驿站市场 | 买卖铜币闭环 |
| P0 | 日计划 UI | 精力条 + 时间槽 |
| P0 | 待收提醒 | 成熟推送 / 角标 + 批量收割 |
| P1 | 工具耐久与修理 | 材料 Sink + 合成价值验证 |
| P1 | 动态价格 | 商队周期 + 简单供需 |
| P0 | 基础合成 | 工作台 + 木板/石砖配方 |
| P1 | 副产物链路 | 麦秆/藤蔓 → 肥料或燃料 |
| P1 | 天气事件 ×2 | 干旱 + 暴雨各 1 条完整链 |
| P1 | 野兽事件 ×1 | 野兔或田鼠完整链 |
| P2 | 住宅 Lv1～2 | 升级 + 维护 + 精力/仓储增益 |
| P2 | 土路与相识 | 道路铺设 + 1 位 NPC 相识线 |
| P2 | 本地天气接入 | 城市级，权重修正 |
| P2 | 账本与 ROI 预览 | 策略反馈 |
