## 1. 主循环

```mermaid
flowchart LR
    A[规划今日行动] --> B[消耗精力开荒]
    B --> C[地块进入可种植状态]
    C --> D[播种/浇水/施肥]
    D --> E[等待生长（现实时间）]
    E --> F[收获]
    F --> G[出售/加工/储存]
    G --> H[购买工具/种子/补给]
    H --> A
```

---

## 2. 开荒子循环（单次行动）

1. **选择目标地块**（查看地形、障碍类型、预估工作量）
2. **选择工具**（效率、耐久、是否匹配障碍）
3. **确认行动** → 消耗**精力** + 占用**时间槽**
4. **结算**：地块状态推进（如：杂草 → 翻土 → 平整 → 可种植）
5. **可能触发**：随机事件（详见 [04-随机事件系统](../04-系统设计/随机事件系统.md)）

## 3. 土地与开荒系统

### 3.1 地块状态机

| 状态 | 说明 | 可进行的操作 |
|------|------|--------------|
| 未探索 | 迷雾覆盖 | 侦察（消耗时间） |
| 原始荒草 | 高杂草、低肥力 | 割草、烧荒（可选） |
| 板结土 | 需翻土 | 锄地、松土 |
| 石砾混合 | 含石块 | 拣石、碎石化 |
| 平整地 | 可播种 | 施肥、播种 |
| 熟化田 | 连续种植后 | 更高产量加成 |
| 休耕地 | 玩家主动休耕 | 恢复肥力 |

**开荒进度示例**（一块标准 1×1 地块）：

```
原始荒草(100%) → 割草(60%) → 翻土(30%) → 平整(0%) → 可种植
```

每次有效劳动减少「剩余工作量」，不同工具效率不同。

### 3.2 障碍类型与对应工具

| 障碍 | 推荐工具 | 低效工具 | 备注 |
|------|----------|----------|------|
| 高草/灌木 | 镰刀、柴刀 | 锄头 | 可能获得纤维、木材 |
| 板结土 | 锄头、犁 | 手 | 消耗精力高 |
| 石块 | 鹤嘴锄、撬棍 | 普通锄 | 石块可收集出售 |
| 树根 | 斧、铁锹 | 镰刀 | 获得木材 |
| 积水/沼泽 | 排水渠、水泵 | 普通工具 | 需前置基建 |

### 3.3 开荒的精力消耗

**基础公式**：

```
精力消耗 = 基础工作量 × 工具系数 × 地形系数 × (1 - 熟练度加成)
```

| 机制 | 说明 |
|------|------|
| 精力上限 | 初始 100，随等级、装备、食物提升 |
| 自然恢复 | 每 2 现实分钟 +6 |
| 睡眠 | 跨日恢复至 80%～100% |
| 食物/药水 | 即时或持续恢复 |

### 3.4 时间冷却系统（v3）

统一时间锚点：**1 时间槽 = 1 现实分钟**；**1 游戏日 = 20 时间槽（20 分钟）**。详见 [time-economy.json](../../config/time-economy.json)。

| 行动类型 | 占用 | 冷却/限制 |
|----------|------|-----------|
| 单次锄地/开荒 | 1 时间槽（**1 min**） | 无 |
| 播种 / 收割 | 各 1 时间槽 | 无 |
| 整块区域烧荒 | 2 时间槽（2 min） | 干燥天气下效率更高 |
| 工具修理 | 1～3 时间槽 | 需在工作台 |
| 驿站交易 | 1 时间槽 | 与商队周期独立 |
| 商队刷新 | — | 每 **48 现实小时** 一次 |
| 作物生长 | T1 **5 min** → T4 **40 min** | 离线继续，成熟后可随时收割 |
| 合成队列 | 1～8 现实分钟 | 离线继续 |

**精力**：基础上限 100，每 **2 现实分钟** 自然恢复 +6。

**设计原则**：

- 精力耗尽后，仍可安排「低精力」活动（规划、交易、研究）
- 作物生长采用**现实分钟**，玩家按自己节奏登录收割即可，详见 [07-作物生长与时间节奏](../04-系统设计/作物生长与时间节奏.md)

## 4. 工具系统

### 4.1 工具属性

| 属性 | 说明 |
|------|------|
| 效率 | 减少工作量的倍率 |
| 耐久 | 使用次数或耐久值，归零需修理 |
| 适用类型 | 对哪些障碍有加成 |
| 精力修正 | 使用该工具时精力消耗增减 |
| 品质 | 普通 / 精良 / 大师，影响以上各项 |

### 4.2 工具列表

| 工具 | 获取方式 | 主要用途 | 经济定位 |
|------|----------|----------|----------|
| 木锄 | 初始赠送 | 基础翻土 | 零成本起点 |
| 铁锄 | 购买/锻造 | 效率 +40% | 第一个里程碑投资 |
| 镰刀 | 购买 | 割草 | 开荒必备 |
| 鹤嘴锄 | 锻造 | 碎石化 | 中期解锁石砾地 |
| 简易犁 | 图纸+材料 | 大面积翻土 | 后期规模化 |
| 水车/水泵 | 基建 | 排水灌溉 | 长期投资 |

### 4.3 工具熟练度

- 长期使用同一类工具 → **熟练度提升** → 精力消耗降低、小概率不耗耐久
- 鼓励专精，也保留「换工具开新区域」的取舍

## 5. 种植与生产系统

### 5.1 作物分级

| 层级 | 代表作物 | 土地要求 | 生长时长（标准） | 净铜/轮 | 风险 |
|------|----------|----------|------------------|---------|------|
| T1 | 土豆、萝卜 | 平整地即可 | **5 分钟** | ~10 | 低 |
| T2 | 小麦、玉米 | 需施肥（可选） | **12 分钟** | ~15 | 中（天气） |
| T3 | 棉花、药草 | 熟化田 | **20 分钟** | ~26～28 | 中 |
| T4 | 稀有药草、经济作物 | 特定地形+设施 | **40 分钟** | ~52 | 高（周期长、占用地块） |

### 5.2 肥力与连作

- 每块地有**肥力值**（0～100）
- 连续种植同种作物 → 肥力下降 → 产量降低
- **轮作、休耕、绿肥**可恢复并提升上限

### 5.3 生长与收割

**无季节限制**：任意时刻满足条件即可播种；生长采用**现实时间**倒计时，**离线继续**；倒计时结束后进入「可收割」，玩家**任意时间**收取，无过期惩罚。

#### 生长流程

```
播种 → 生长中（现实时间倒计时）→ 可收割 → 玩家收取 → 地块可再种
```

| 项目 | 规则 |
|------|------|
| 播种时机 | 随时，仅受土地状态、种子库存限制 |
| 生长计时 | 现实时间，见 [07-作物生长与时间节奏](../04-系统设计/作物生长与时间节奏.md) |
| 成熟后 | 永久可收，品质不随等待下降 |
| 地块占用 | 未收前不可在同一块地再种 |
| 提醒 | 推送 / 角标：「N 块地已成熟」 |

#### 可选护理（缩短周期或增产）

| 操作 | 效果 |
|------|------|
| 浇水 | 剩余生长时间 -10%（每块地每日 1 次） |
| 施肥 | 剩余时间 -15%，产量 +10% |
| 雇工代收 | 成熟后自动收取（产量 80%） |

#### 策略取舍

- 成熟作物不占精力，但**占用地块**——种太多 T3/T4 长时间作物会导致可耕地紧张
- 「开荒扩地」与「等待现有作物成熟」形成自然节奏，无需季节外力施压
- 随机事件可能**暂停或延长**进行中作物的生长，见 [04-随机事件系统](../04-系统设计/随机事件系统.md)

### 5.4 加工链与材料

种植、开荒产生的原料可进入**合成系统**，转为更高价值物资。完整配方与产出机制见 [08-材料合成与产出](../04-系统设计/材料合成与产出.md)。

```
T0 原料（开荒/种植/采集）→ T1 基础加工 → T2 中间品 → T3 成品
                                              ↓
                                    出售 / 工具 / 基建 / 肥料消耗
```

**示例链路**：

```
小麦 → 面粉 → 面包（溢价出售）
棉花 + 麻绳 → 粗布（溢价出售）
野纤维 → 麻绳 → 围栏/织机原料
铜矿石 + 木炭 → 粗铁锭 → 精铁件 → 工具修理
```

加工消耗**现实时间**与**设施队列**，与作物生长并行，不占地块。
