# 商业化方案

---

## 1. 定位

《开荒》以**休闲策略 + 情感归属**为主，商业化服从体验，避免 Pay-to-Win。

## 2. 可接受付费点

| 类型 | 示例 | 原则 |
|------|------|------|
| 外观 | 工具皮肤、农场装饰、住宅外观 | 不影响数值 |
| 便利 | 账本扩展、地图标记、仓库页 | 不直接卖资源 |
| 通行证 | 声望加速、限定装饰 | 可选，非 P2W |

## 3. 明确避免

| 类型 | 原因 |
|------|------|
| 直接售铜币/材料 | 破坏经济平衡 |
| 跳过开荒/瞬间成熟 | 破坏核心 loop |
| 付费独家作物/工具数值 | 破坏公平 |

## 4. 与人性层关系

- 伴侣、住宅剧情：**不**付费解锁
- 装饰性家具、庄园皮肤：可付费
- 关系加速：**不做**
