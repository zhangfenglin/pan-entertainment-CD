# 界面设计要点

[← 返回总索引](../README.md)

---

## 1. 信息架构

```
主界面
├── 地图（默认）
├── 待收 / 生长
├── 背包 / 材料
├── 市场
├── 合成 / 设施
├── 家园 / 道路 / 关系
└── 菜单（账本、设置、图鉴）
```

## 2. 关键界面

| 界面 | 功能 |
|------|------|
| 地图视图 | 地块状态、障碍图标、预估 ROI |
| 日计划面板 | 精力条、时间槽、行动队列 |
| 待收列表 | 可收割地块聚合、批量收取 |
| 生长进度 | 现实时间倒计时、预计成熟时刻 |
| 市场面板 | 动态价格、趋势、商队倒计时 |
| 账本 | 收支明细、地块累计利润 |
| 开荒预览 | 工具选择 → 精力/时间/耐久预览 |
| 天气灵感条 | 本地天气风险建议（可选） |
| 事件日志 | 前兆、爆发、应对与损失 |
| 家园视图 | 住宅等级、升级、维护 |
| 道路模式 | 铺路预览、材料消耗 |
| 关系面板 | 好感、阶段、赠礼、协作冷却 |
| 材料图鉴 | 来源、用途、库存、市价 |
| 合成台 | 配方、队列、利润对比 |

## 3. 交互原则

| 原则 | 说明 |
|------|------|
| 少打断 | 成熟/事件用角标+待办，非强制弹窗 |
| 可批量 | 收割、出售、合成支持多选 |
| 决策可见 | 卖原料 vs 合成、升级 vs 买工具 有对比数字 |
| 碎片友好 | 单次 session 常用功能 ≤2 次点击到达 |
