## 1. 背景

玩家因故来到一片**被遗忘的边境荒原**——土壤板结、杂草丛生、偶有石块与枯木。当地仅有零星流浪商队与旧驿站，无现成农田。玩家需从零开始，用劳动换土地，用土地换生存，再换更大规模的开荒能力。

## 2. 地图结构（由近及远）

```
[安全区：旧驿站 / 简陋居所]
    ↓
[近郊荒地] → [灌木丛] → [石砾地] → [沼泽边缘] → [远郊未探明区域]
```

| 区域 | 特点 |
|------|------|
| 近郊 | 开荒成本低，适合新手与基础作物 |
| 中距 | 需更好工具与更多精力，回报更高 |
| 远郊 | 高风险（天气、野兽事件），高价值作物与稀有资源 |

## 3. 主角设定

- **身份**：勤恳农场主，无特殊超能力，靠工具与规划成长
- **成长线**：体力上限、工具熟练度、农业知识、商业信誉、居所与关系

## 4. 叙事基调

| 维度 | 取向 |
|------|------|
| 情感 | 从荒原到家园的踏实感，非末日生存 |
| 冲突 | 人 vs 土地、人 vs 自然事件，轻度人际温暖 |
| 节奏 | 日常劳动为主，事件点缀；无强制季节压迫 |
| 人称 | 第二人称旁白 + 雇工/NPC 口语化事件 |

## 5. 关键 NPC 生态

| 类型 | 代表 | 叙事作用 |
|------|------|----------|
| 驿站掌柜 | 商队、贷款 | 经济枢纽 |
| 可结识同伴 | 阿禾、老周等 | 生活线与协作 |
| 流浪商队 | 周期性出现 | 世界联通感 |
| 邻庄信使 | 每 7 日 | 外部需求与声望 |
