# MVP 功能清单

[← 模块索引](./README.md) | [返回总索引](../README.md)

可玩原型的最小系统集，按优先级排列。

| 优先级 | 系统 | 说明 |
|--------|------|------|
| P0 | 地块开荒 | 1 种障碍 + 2 种工具 + 精力/时间消耗 |
| P0 | 基础种植 | T1 作物 1～2 种，现实时间生长、成熟可收 |
| P0 | 驿站市场 | 买卖铜币闭环 |
| P0 | 日计划 UI | 精力条 + 时间槽 |
| P0 | 待收提醒 | 成熟推送 / 角标 + 批量收割 |
| P0 | 基础合成 | 工作台 + 木板/石砖配方 |
| P1 | 工具耐久与修理 | 材料 Sink + 合成价值验证 |
| P1 | 动态价格 | 商队周期 + 简单供需 |
| P1 | 副产物链路 | 麦秆/藤蔓 → 肥料或燃料 |
| P1 | 天气事件 ×2 | 干旱 + 暴雨各 1 条完整链 |
| P1 | 野兽事件 ×1 | 野兔或田鼠完整链 |
| P2 | 住宅 Lv1～2 | 升级 + 维护 + 精力/仓储增益 |
| P2 | 土路与相识 | 道路铺设 + 1 位 NPC 相识线 |
| P2 | 本地天气接入 | 城市级，权重修正 |
| P2 | 账本与 ROI 预览 | 策略反馈 |

## 验收标准

- 新用户无教程外说明，30 分钟内完成首次出售
- P0 全部完成后可内部试玩一轮 3 小时 session
