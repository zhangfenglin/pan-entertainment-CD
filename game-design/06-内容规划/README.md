# 新手引导（摘要）

## 设计目标

- 30 分钟内完成 **开荒 → 种植 → 成熟 → 出售** 闭环
- 以操作驱动教学，生活线/合成线首日后解锁

## 首日流程

| 步骤 | 教学内容 |
|------|----------|
| 1 | 移动、视角、交互 |
| 2 | 选工具、精力、时间槽（开荒） |
| 3 | T1 播种、生长倒计时 |
| 4 | 成熟提醒、待收列表 |
| 5 | 收割、批量收取 |
| 6 | 驿站市场出售 |
| 7 | 可选：工作台合成木板 |

完整版见 [新手引导.md](./新手引导.md)。
