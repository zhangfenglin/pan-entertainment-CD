# 数值框架（摘要）

## 首日体验目标

| 目标 | 指标 |
|------|------|
| 完成首次开荒 | 30 分钟内 3～5 格 + 首批 T1 |
| 首次出售 | 50～80 铜 |
| 首次资源紧张 | 引导订单/副产物出售 |

## 关键比率

| 比率 | 目标值 |
|------|--------|
| 劳动 : 等待 | 40% : 60% |
| 开荒回本 | 1.5～3 轮种植循环 |
| 加工溢价 | 2～5 倍 |
| 合成溢价 | 1.15～1.5× |

完整版见 [数值框架.md](./数值框架.md)、[术语表.md](./术语表.md)。
