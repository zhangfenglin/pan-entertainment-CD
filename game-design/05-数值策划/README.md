# 数值框架（摘要 · v3.1）

## 时间锚点

| 参数 | 值 |
|------|-----|
| 时间槽 | **1 现实分钟** |
| 游戏日 | **20 分钟** |
| 商队周期 | 48 现实小时 |
| 早期净铜/小时 | 80～120 |

## 首日体验目标

| 目标 | 指标 |
|------|------|
| 完成首次开荒 | 15 分钟内 3～5 格 + 首批 T1 |
| T1 首轮成熟 | **5 分钟** |
| 首次出售 | 30～50 铜 |
| 首次资源紧张 | 引导订单/副产物出售 |

## 关键比率

| 比率 | 目标值 |
|------|--------|
| 劳动 : 等待 | 50% : 50% |
| 开荒回本 | 8～10 轮 T2（≈ 1.5～2 活跃小时） |
| 作物 T1→T4 | **5 / 12 / 20 / 40** 分钟 |
| 合成溢价 | 1.15～1.5× |

完整版见 [数值框架.md](./数值框架.md)、[术语表.md](./术语表.md)。
