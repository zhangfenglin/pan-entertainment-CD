## 1. 首日体验目标

| 目标 | 指标 |
|------|------|
| 完成首次开荒 | 30 分钟内完成 3～5 格开荒 + 种下第一批 T1 |
| 完成 T1 首轮回收 | T1 标准 **5 分钟**后成熟，首 session 内可体验完整闭环 |
| 首次出售 | 获得 **30～50 铜**（v3 单价下调，量增） |
| 首次资源紧张 | 引导完成订单/副产物出售 |

详见 [新手引导](../06-内容规划/新手引导.md)。

## 2. 统一时间锚点（v3）

| 参数 | 值 | 配置 |
|------|-----|------|
| 时间槽 | **1 现实分钟** | `time-economy.json` |
| 游戏日 | **20 分钟**（20 槽） | 同上 |
| 精力上限 | 100 | 同上 |
| 精力自然恢复 | +6 / 2 分钟 | 同上 |
| 商队周期 | 48 现实小时 | 同上 |
| 机会成本 | 1.5 铜 / 分钟 | 同上 |

## 3. 关键比率（v3 起点）

| 比率 | 目标值 |
|------|--------|
| 劳动时间 : 等待时间 | 45% : 55%（节奏加快后略偏劳动） |
| 开荒投资回本 | 约 **8～10 轮** T2 种植（≈ **1.5～2 活跃小时**） |
| 早期净铜/活跃小时 | **80～120 铜** |
| 中期净铜/活跃小时 | **150～220 铜** |
| 成熟农场利润率 | 15%～25%（按商队周期估算） |
| 合成溢价 | 1.15～1.5×（见 [材料合成](../04-系统设计/材料合成与产出.md)） |
| 作物生长 T1→T4 | **5 / 12 / 20 / 40** 分钟 |
