## 1. 首日体验目标

| 目标 | 指标 |
|------|------|
| 完成首次开荒 | 30 分钟内完成 3～5 格开荒 + 种下第一批 T1 |
| 首次出售 | 获得 50～80 铜 |
| 首次资源紧张 | 引导完成订单/副产物出售 |

详见 [新手引导](../06-内容规划/新手引导.md)。

---

## 2. 关键比率（建议起点）

| 比率 | 目标值 |
|------|--------|
| 劳动时间 : 等待时间 | 40% : 60% |
| 开荒投资回本 | 约 1.5～3 轮完整种植循环 |
| 加工溢价 | 2～5 倍 |
| 成熟农场利润率 | 15%～25%（按周估算） |
| 重大基建占当周收入 | 30%～50% |
| 合成溢价 | 1.15～1.5×（见 [材料合成](../04-系统设计/材料合成与产出.md)） |
