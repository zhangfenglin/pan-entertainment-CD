## 1.1 核心概念

**《开荒》** 是一款以**土地开垦 + 农场经营**为核心的休闲策略游戏。玩家扮演一位来到荒芜之地的勤奋农场主，从一片未开发的野地出发，通过工具、精力与时间，逐步将荒地变为高产农田，并在此基础上建立可持续的农场经济。

## 1.2 设计目标

| 维度 | 目标 |
|------|------|
| 情感体验 | 从「一无所有」到「有家、有路、有人同行的庄园」 |
| 核心乐趣 | 规划开荒顺序、工具搭配、精力与时间分配 |
| 策略深度 | 短期收益 vs 长期投入、风险与回报权衡 |
| 经济闭环 | 开荒 → 种植 → 出售/加工 → 再投资开荒 |
| 沉浸感 | 可选接入玩家本地天气，增强真实代入 |

## 1.3 一句话卖点

**「每一锄下去，都是未来的一亩良田。」**

## 1.4 目标用户

| 类型 | 特征 | 需求 |
|------|------|------|
| 休闲上班族 | 碎片时间、晚间/周末 | 短周期作物、成熟可收、无季节压迫 |
| 模拟经营爱好者 | 喜欢规划与建设 | 经济闭环、材料合成、住宅道路 |
| 慢节奏玩家 | 偏收集与归属 | 生活线、伴侣、庄园成长 |

---

## 2. 玩家核心决策

玩家在任意时刻都在回答四个问题：

1. **今天体力花在哪？** — 开荒、种植、应对事件
2. **种什么、何时收？** — 市场、地块占用、生长周期
3. **钱是先还债还是先买犁？** — 现金流与长期投资
4. **要不要先铺条路、升一级宅子？** — 生活线 vs 产能线（见 [生活与社群](../04-系统设计/生活与社群.md)）
